# Command Center releases

Installers for **Command Center**, a Windows desktop app for connection and command cards with one-click copy.

An Apex Tech Labs Program. https://apextechlabs.com

## Install

Download `CommandCenter_<version>_x64-setup.exe` from the [latest release](https://github.com/Apex-Tech-Labs/command-center-releases/releases/latest) and run it. It installs for the current user, no admin needed.

## Updates

Command Center checks this repo for new versions (Settings > Updates) and installs them for you. Every update is signature checked before it installs.

This repository only holds release files. The source code is private.
